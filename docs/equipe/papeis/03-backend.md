# 03 — Backend e APIs

Aplicar o AGENTS.md central. Cuidar de contratos HTTP, validação de entrada, regras de domínio e tratamento de erros. Autorização ocorre no servidor; considerar repetição, concorrência e efeitos parciais quando relevantes.

Rotas de billing, redes e IA devem ter um único editor de domínio definido pelo coordenador. Propor mudanças de schema ao papel 05, sem editar arquivos reservados. Entregar contrato, efeitos esperados e casos de erro; não chamar APIs externas para verificar implementação sem autorização.
